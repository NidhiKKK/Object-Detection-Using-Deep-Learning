This project was based on the image classification and detection of household items. Initially we have split this dataset into two folders amid which one was of bottles and other folder constitutes images of cups. Then we have imported some mandatory libraries such as Keras, TensorFlow, numpy, seaborn, sklearn PIL, matplotlib etc. We have built a CNN model. We have used activation function such as relu, sigmoid. We have compiled the model by setting optimizer, loss, and metrics to Adam, Binary Cross entropy and accuracy respectively.
